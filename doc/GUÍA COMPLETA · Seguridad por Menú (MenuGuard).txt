## 📦 Preguntas frecuentes (actualizadas)

¿Qué pasa si el menú no está en table_men_rutas?
El guard hace menuIdPorRuta() → null → deja pasar. Sin patrón registrado, no hay
protección. Después de la reconstrucción, todos los patrones están registrados.
Si agregas un módulo nuevo, tienes que registrar su patrón desde la UI de Menús
o por SQL.

¿Qué pasa si el usuario es del depto Sistema?
Pasa siempre, sin importar si tiene o no el menu_id.
Es una excepción para que el admin nunca se quede fuera.

¿Qué pasa si quito el menu_id a un usuario?
En la siguiente petición, el guard lo bloquea. No hay que reiniciar sesión ni
tocar código.

¿Qué pasa si agrego el menu_id a un usuario?
En la siguiente petición, ya puede entrar. Sin tocar código.

¿Los IDs viejos (1010, 1006, etc.) siguen sirviendo?
NO. Fueron eliminados en la reconstrucción. Ahora los IDs son 1502 (Personal),
1501 (Usuarios), 1601 (DataVenta), etc. Cualquier código que asigne los IDs
viejos fallará silenciosamente.

¿Puedo revertir el guard?
Sí. Quita la línea MenuGuard::check(); del controlador. No hay que tocar BD.

¿Cómo se administra el acceso desde la UI?
Menú /menu → abrir el módulo → pestaña "Usuarios" o "Departamentos" → asignar/quitar.

¿Qué hago si el guard bloquea a alguien que SÍ debía pasar?
1. Verificar que el menu_id del módulo esté en table_men_rutas con activa = 1.
2. Verificar que el usuario tenga el menu_id en table_men_usuario_menu o que su
   depto lo tenga.
3. Verificar que el usuario esté activo.
4. Si todo eso está OK y sigue bloqueado → revisar MenuGuard::check()
   (log en db-errors.log).

¿Cómo restauro los menús si algo sale mal?
El respaldo está en:
- backup_men_menu_20261022
- backup_men_rutas_20261022
- backup_men_usuario_menu_20261022
- backup_men_departamento_menu_20261022

Restaurar:
DELETE FROM table_men_usuario_menu;
DELETE FROM table_men_departamento_menu;
DELETE FROM table_men_rutas;
DELETE FROM table_men_menu;

INSERT INTO table_men_menu SELECT * FROM backup_men_menu_20261022;
INSERT INTO table_men_rutas SELECT * FROM backup_men_rutas_20261022;
INSERT INTO table_men_usuario_menu SELECT * FROM backup_men_usuario_menu_20261022;
INSERT INTO table_men_departamento_menu SELECT * FROM backup_men_departamento_menu_20261022;
