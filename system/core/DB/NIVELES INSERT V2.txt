🟡 Nivel 1: Entidades Principales
Estas tablas requieren que el Nivel 0 esté cargado.

Estas tablas conectan entidades del Nivel 1 con configuraciones del Nivel 0.
table_alm_relacion_producto (Requiere: Producto, Proveedor)

table_recovery_requests (Requiere: Usuario)

🔴 Nivel 3: Transacciones "Cabecera"
Aquí empiezan los movimientos operativos. Requieren usuarios y flotas ya creados.
table_alm_despacho (El núcleo del sistema. Requiere: Flota, Usuario Creador, Usuario Aprobador)
table_flota_mantenimiento (Requiere: Flota, Usuario)
table_flota_status (Requiere: Flota, Usuario)

🟣 Nivel 4: Documentos Derivados
Documentos que nacen a partir de un Despacho.
table_alm_requisicion (Requiere: Despacho, Flota, Usuario)
table_compras_pendientes (Requiere: Despacho, Flota, Producto)
table_alm_relacion_despacho (Tabla pivote. Requiere: Despacho, Producto)

⚫ Nivel 5: Detalles Finales
El último nivel de detalle.
table_alm_requisicion_detalle (Requiere: Requisición, Producto)
table_compras_costos (Requiere: Compra Pendiente, Usuario)
